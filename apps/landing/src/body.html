Verification

How we decide what's real.

Every event is checked before it counts. Each filtered one is kept with its reason code, so anyone can see why it was left out.

48 events arrive
Counted as verified40
Filtered, with a reason85 bots · 2 replays · 1 rate limit
Verified

Passed every check below. Only these events count as real use.

Ledger-checked

Matched on the public ledger. Daily records are compared with Stellar's own data before a day counts.

Filtered

Set aside, with the reason. Each one keeps its reason code, so anyone can see why.

Self-reported

Sent by the project's own servers. API numbers can't be proven independently, so they are labelled.

Not measured

Gaps marked clearly. A day without data is labelled as such, so zero always means zero.

Privacy and security

Private by design. Safe to embed.

UsageMap measures apps, not people. Everything below is documented, tested and public.

Privacy

  • Cookie-freeThe browser keeps only the visitor's own opt-out choice.

  • IP addresses stay in memoryUsed for one request's checks, then discarded.

  • Wallet addresses and keys strippedRemoved before anything is stored.

  • Privacy signals honouredGlobal Privacy Control and Do Not Track are respected.

Compliance, stated plainly

  • Data stays in the EUData is processed and stored in the EU.

  • Consent-free in many jurisdictionsWhere the law requires consent, one setting switches to consent-gated mode. See the country table.

  • Erasure in a few clicksTeams preview, confirm and get a completion report, all audited.

Security

  • Pinned trackerEvery site loads a fixed version with an integrity hash; nothing updates remotely. Teams upgrade on purpose.

  • Isolation in the databaseRow-level security on every table, checked by an isolation test suite on every build.

  • Ad-blocker-safe namesScript and endpoints named so common filter lists don't block them.

  • Target: fixes within 24 hoursFor critical and high vulnerabilities.

Operations and handover

Run as a shared service. Ready to hand over.

The ecosystem gets a working shared service from day one, and everything another operator needs to take it over.

  • Free

    No fees for projects, SCF or anyone else.

  • 99.99 %

    Ingestion availability committed on the scale-out profile; dashboard availability 99.90 %. The single-host launch setup targets 99.5 %.

  • 24 h

    Target for critical and high security fixes in production.

  • 5 / 10 days

    Support: first answer within 5 business days, resolved within 10, on a public issue tracker.

  • Every 30 s

    Availability probed and published monthly with the raw data and coverage, so anyone can recompute it.

Handover, rehearsed

  • One open-source monorepo: code, infrastructure as code, runbooks, dashboards
  • No secret only we hold; nothing tied to a person
  • Full data migration, rehearsed in a drill
  • Domains transferred or permanently redirected
  • Built on Umami, kept unmodified and pinned
